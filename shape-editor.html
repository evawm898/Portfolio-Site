Shape

what this stage is
Tracing and editing are the same action here: drag points against the calibrated backdrop from Upload and watch the 3D shell update live — one set of curve editors, not two. A miss-click on empty canvas adds a point to the active layer below; drag an existing point to move it; right-click a point to delete it (silhouette layers keep a minimum of 2). This page has no server. Curve editing, 3D regeneration, circumference, and monotonicity are genuinely live; the full curvature/seatability sweep still needs Python and shows a labeled, bake-time snapshot rather than a live number.

Shells

what this stage is
Not one saved shell — a library you build up over time. Saving creates a named entry with a timestamp and a thumbnail; nothing leaves the app, it's stored in this browser. Opening one loads it into Shape; duplicating forks it so you can explore a variant without touching the original. Layouts (Panels tab) belong to a specific shell — saving over a shell that owns layouts re-checks their panel standoff first and names what breaks.
