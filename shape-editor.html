Stage 2 · Shape

Tracing and editing are the same action here: drag points against the calibrated backdrop from Stage 1 and watch the 3D shell update live — one set of curve editors, not two. A miss-click on empty canvas adds a point to the active layer below; drag an existing point to move it; right-click a point to delete it (silhouette layers keep a minimum of 2). This page has no server — reachable from any browser via this deploy preview. Curve editing, 3D regeneration, circumference, and monotonicity are genuinely live; the full curvature/seatability sweep still needs Python and shows a labeled, bake-time snapshot rather than a live number.

Point density (adaptive placement)

…
Points are placed adaptively (worst-residual-first against a dense reference), not uniformly — fewer points where the curve is straight, more where it bends. Moving a slider resamples the curve as it stands right now (hand edits included) at the new count — it does not just add or remove handles at fixed spots. Scrubbing a slider back and forth is lossless; a fresh hand-drag on the canvas resets what "now" means for the next resample.
